Plith · Phase 6

Classic OSD Redesign

The notch got a bespoke surface. Classic did not, and it is still the default on every install — so it gets the same pass: a level you can actually see, icons that belong to this app, and colours that mean something.

What was wrong

Three defects, all visible in a screenshot and none caught by a test.

The track was invisible

2 DIP tall at low opacity on a dark card. The number carried the whole reading, which makes the bar decoration — and a level you cannot see at a glance is the one thing an OSD exists to show.

Borrowed icons

Segoe MDL2 glyphs — the same speaker Windows' own flyout draws. Nothing said Plith, and the set is not ours to shape: seven of ten weather glyphs turned out not to exist in the font at all.

The device line ran on

Logitech G733 Gaming Headset (2- G733) ellipsed mid-word, so the useful half was the half cut off. The suffix Windows appends carries no information a person needs.

Anatomy

Six decisions, each answering something the old card left to chance.

Logitech G733
Voicemeeter · A1
62%
01
Speaker state, not a decoration
Three shapes — full, low below 33 %, crossed when muted. The icon alone answers "is my sound off?" without reading a number.
02
Short device name
Everything from the first bracket or dash onward is dropped, so Logitech G733 Gaming Headset (2- G733) becomes Logitech G733. One line, no ellipsis.
03
Which rail this is
The bus line — Voicemeeter · A1, Windows · Output, Muted. On a machine with Voicemeeter plus Sonar plus a headset, the number alone is ambiguous.
04
Level as a number, once
Tabular figures so the digits do not shuffle as the value changes, and the per-cent sign set smaller because it never changes.
05
A track you can see
6 DIP with a soft glow at the fill. The thing the OSD exists to show is now the thing with the most contrast on the card.
06
Wide enough for the row that needs it
300 DIP, set by the media state rather than the bare volume one. The card has one width in every state, so the fullest row picks the number — the same rule the notch's fixed frame follows.
07
Titles scroll, they do not ellipse
Measured overflow starts a slow scroll at a constant 28 dip/s; anything that fits sits still. An ellipsis on a track name hides the half you were reading, and the media row is the one place on the card where the text is the content.
08
A threshold tick
A hairline at 85 %, drawn only once the level is near it. It gives the colour change a cause instead of making it look like a glitch.

The accent setting stays separate. A person who picks a purple accent gets a purple card chrome, not a purple level — because the level's colour is information. When Colour the level is off, the fill takes the accent and the thresholds stop applying; that is the only case where the two meet.

Drawn for this app: 1.6 stroke on a 24 grid, round caps and joins, fills only where a shape needs to read solid at 13 px. No system font, so nothing can go missing on a machine that ships a different Segoe.

Motion

Classic appears and disappears; it does not morph. That is the whole difference from the notch, and the timings keep it that way.

MomentWhat movesTiming
AppearOpacity 0 → target, plus 8 DIP rise from the edge it sits on 180 ms · cubic out
Level change while shownThe fill width only. The card does not re-enter. 120 ms · cubic out
Threshold crossedFill and number colour, together 140 ms · linear
Media card arrivesCard height, with the row fading in behind it 200 ms · cubic out

DismissOpacity only. No slide — a card sliding away reads as dragged. 160 ms · cubic in

What changes in the app

Concrete edits, so this page is a work item rather than a picture.

WhereChange
AudioCardView.xaml Track height 2 → 6, opacity 0.25 → 0.10 white ground + full-strength fill, plus the glow and the 85 % tick.
Icons/PlithIcons.xaml New — the nine PathGeometry resources above, replacing every FontIcon bound to Segoe MDL2.
WeatherCodeMap.cs Glyph code points and the font-existence test retire with them; the map returns an icon key instead.
MediaCardView.xaml Title and artist move into a clipped host with a TranslateTransform; the scroll is a DoubleAnimation started from a measured overflow on SizeChanged — re-measured, never cached, because a title that changes while the card is up is exactly the case a one-shot measurement gets wrong.
AudioCardViewModel ShortDeviceName and BusLabel, both pure and both unit-testable — which the current inline string formatting is not.
ThemePalette Signal / Caution / Alarm become named brushes. Today the threshold colours are literals in two files that have already drifted apart.
check-a11y.ps1 Gains a rule: no FontFamily="Segoe MDL2 Assets" anywhere under Views/.

Before it counts as done

None of this is verifiable from a build. Slice 2 shipped green on the suite and the lint, then crashed on first hover and drew half its content over the desktop. The card is rendered by a layered window that no capture path can photograph over RDP, so every item here — the track's contrast over a bright wallpaper, the icons at 100 % and 150 % DPI, the name shortening against the real G733 string, the threshold tick appearing when it should — needs a physical console session and a pair of eyes. It goes in the ledger as open until then.
