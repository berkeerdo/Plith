Live states

Rest is a shape, not a strip. Hover acknowledges the pointer without opening anything. A click opens the panel — that separation is what keeps the top of the screen usable, because an open panel is solid to the mouse and a closed one is not there at all.

Motion

One progress value drives width, height, radius, shadow and content opacity together. Four parallel clocks on one transition can be stopped or retargeted independently, and any of those leaves the shape in a state no single value describes.

Open
Leaves fast, spends the rest settling. The decelerating tail is what reads as springy.
340 ms · quintic out
Close
Accelerates away; content fades first.
260 ms · cubic in
Peek / unpeek
Quick enough to feel like a response, not an animation.
160 ms · cubic
Content fade
Starts only once the shape has mostly settled.
from t = 0.55

Ordering is the effect. The shape settles first and the content arrives into it. Fading content in while the surface is still moving reads as a window being resized — the one thing a notch must never look like.

Theme, accent, and the bezel

The notch takes the theme, but not all of it — and today it takes too much. The resting shape is currently painted with OsdSurfaceBrush, the same brush as a Classic card, which means on the light theme the notch becomes a pale bar sitting on a pale desktop. That stops being a cutout and becomes a floating tab.

When the notch is not there

Picking Notch does not mean the notch is always what you get. Plith drops to Classic whenever a window covers the monitor, and comes back when it stops.

Behaviour

Covered means Classic

The notch lives flush against the top edge, where a covering window either hides it or it sits on top of something running full-screen. Classic keeps a 96 dip margin and was built to appear over exactly that. So WantsNotch is Notch selected and nothing covering the monitor, and the presentation is rebuilt on the edge — including back to the notch when the game closes.

Precision

It is not “games”

The signal is any window covering the monitor: a full-screen game, a borderless maximised browser, a full-screen video. Calling it a game switch in the UI would be a lie a person catches the first time they maximise a video. Note this is separate from Hide during full-screen video, which decides whether the OSD appears at all — this one only decides which shape it takes.

Settings

Say it on the page

Otherwise the first bug report writes itself: pick Notch, launch a game, see the Classic card, conclude the setting did not save. The Style row carries the sentence, and the preview shows the fallback rather than describing it.

Consequence

Classic is never optional

Every Notch user is also a Classic user, several times a day. That is the argument for the Classic redesign being part of this work and not a later tidy-up — half the sessions of the “new” presentation are the old one.

The OSD itself

A volume key is not a request to open anything. Today it opens the same panel a click does, which is why the OSD reads as a window rather than as feedback. In notch mode it becomes a HUD: the resting shape stretches into a short bar, says one thing, and returns.

Two shape families

The notch is never a card. It is one surface that takes one of two shapes, and which shape it takes says who started the interaction.

You did something

Event HUD

A volume key, a track change. Short and wide, one line, gone in two seconds. It is an answer, not a place — so it never grows tall and never shows a page dot.

You went looking

Widget page

Opened by a click, held while you use it, paged sideways. One fixed frame, whichever widget is in it.

Widgets

One widget per page, and every page is the same size. Two earlier passes let the page drive the size — first both dimensions, then only the height. Both read as the notch jumping around while you swiped. A steady frame with content moving through it is the only version that reads as one object.

Built

Clock

Time and date, centred. Carries empty space on purpose — a clock centred in a steady frame reads as deliberate, a frame that shrinks to hug it reads as unstable.

Planned

Weather

The sky is not an icon on the page — the sky is the page, edge to edge, the way Samsung's weather app does it. Condition and time of day set the gradient; sun bloom, drifting cloud and falling rain sit on top of it, and a scrim keeps the numbers legible whatever the sky is doing.

Partly built

Media

Art, title, transport. The buttons work — press play here and it responds, because a widget you can only look at is a notification.

Planned · interactive

Candidates

Next

Calendar peek, a timer you start from the notch, mic mute state. Each earns a page only if it is worth a swipe — the pager is not a place to put everything.

First look of the day is an event; every look after it is wallpaper. The first time you open the weather page on a given day the sky arrives expansively — the gradient swells in, the sun rises into frame, cloud sweeps across — and then settles into a slow ambient loop it keeps for the rest of the day. A flourish that fires on every glance stops meaning anything, and on a surface that lives at the top of the screen it would go from delightful to tiring inside a day. Wheel deltas are not page counts. One physical swipe emits a stream of them, so delta accumulates and commits a single page per threshold, then waits for the accumulator to fall back near zero.

Two rules that are not style

Structural

The alpha is the hit mask

The window WPF paints must be the top-level window — per-pixel opacity applies to nothing else. Given that, transparent pixels pass the mouse through and drawn ones receive it, with no filter, no click-through bit, no region. Every attempt to patch around it failed, in both directions.

Cost

Motion stops when the panel closes

The window is never hidden in notch mode, so an animation left running is a permanent CPU cost on an overlay that is invisible most of the time. Weather motion starts on open and stops on collapse — and gets measured, not assumed.
