# Contributing to Plith

Thanks for your interest. Plith is a small, focused Windows audio OSD; the
scope is intentionally narrow, so please open an issue to discuss any feature
larger than a bug fix before writing code.

## Ways to help

- **Report bugs.** Include your Windows version (`winver`), whether
  Voicemeeter is running, and repro steps. If Plith crashed, the last few
  lines of `%LOCALAPPDATA%\Plith\logs\` are gold.
- **Suggest features** by opening an issue tagged `enhancement` with the
  concrete use case. Broad "add X" requests without context tend to sit.
- **Submit pull requests** for fixes or small improvements. For anything
  cross-cutting, open the discussion first.

## Development setup

Requirements:

- **Windows 11** (Windows 10 build 22000+ also works).
- **.NET 10 SDK** — `winget install Microsoft.DotNet.SDK.10`
- **PowerShell 7+** — installed by default on Win11.
- Optional: **Voicemeeter Banana** or **Voicemeeter Potato** if you want to
  exercise the Voicemeeter integration path.

```powershell
git clone https://github.com/berkeerdo/Plith.git
cd Plith
dotnet build src/Plith/Plith.csproj -c Release
dotnet run --project src/Plith
```

Run the tests:

```powershell
dotnet test tests/Plith.Tests/Plith.Tests.csproj
```

Run the accessibility check (fails if an interactive XAML control has no
`AutomationProperties.Name` or `AutomationProperties.LabeledBy`; CI runs this
on every pull request and push touching `src/**`):

```powershell
pwsh -NoProfile -File scripts/check-a11y.ps1 -Root src
```

Produce a signed release artifact (needs the local self-signed cert):

```powershell
pwsh scripts\build-release.ps1
```

## Project layout

See [README#architecture](README.md#architecture) for the full tree. The
short version:

- `src/Plith/Services/` — audio sources (Voicemeeter, NAudio), SMTC media,
  orchestrator, hotkeys, tray, flyout suppression.
- `src/Plith/Views/` — WPF windows. `OsdContent.xaml` + `MediaCard.xaml`
  are the OSD card; `SettingsWindow.xaml` is the Settings UI.
- `src/Plith/Resources/` — palettes (`Palette.Dark.xaml`,
  `OsdPalette.Dark.xaml`), themes, icons.
- `src/Plith.Installer/` — WPF installer wizard that stages the binary and
  configures signing / UIAccess.

## Coding conventions

- **English only** in code, comments, docs, and commit messages.
- **Conventional Commits**: `type(scope): subject`. Examples in `git log`.
- Comments are for the **why**, not the **what** — prefer good naming.
- No trailing "co-authored-by" / "generated by" tags in commit messages.
- Nullable reference types are enabled; keep them enabled.
- Analyzer profile is `AnalysisMode=Recommended`. New warnings must be
  fixed or explicitly suppressed with a justification comment.

## Game mode and anti-cheat

Plith uses `CreateWindowInBand` (documented Windows API; the same technique
MSI Afterburner and RTSS use) and does not read game memory or inject
input. That said, competitive anti-cheats (Vanguard, EAC) may flag any
UIAccess overlay. Test Game-mode changes on a spare game account first,
and never on a ranked ladder.
